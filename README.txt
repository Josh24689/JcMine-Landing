# JcMine Landing Page

Static landing page modeled on the structure and feel of the EarnFun landing page.

## Deploy
Upload the contents of this folder to GitHub Pages, Cloudflare Pages, Netlify, or any static host.

The APK is included as `jcmine.apk`, and all primary download CTAs point to it.

## Files
- index.html
- styles.css
- script.js
- assets/jcmine_logo.png
- jcmine.apk
